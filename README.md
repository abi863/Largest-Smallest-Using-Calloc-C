# Largest and Smallest Elements Using calloc() in C

## Description
This C program dynamically allocates memory for an array of integers using `calloc()`. It reads the elements, finds the largest and smallest values, and releases the allocated memory using `free()`.

## Concepts Used
- Dynamic memory allocation
- `calloc()`
- Pointers
- Arrays
- Conditional statements
- `free()`

## How to Run
```bash
gcc calloc_max_min.c -o calloc_max_min.exe
./calloc_max_min.exe
```

## Language
C
